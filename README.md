# Бекенд для бронирования авиабилетов (Python)

[![hexlet-check](https://github.com/unlaudd/middle-python-project-428/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/unlaudd/middle-python-project-428/actions)

Реализуйте бекенд сервиса бронирования авиабилетов: справочник городов, поиск рейсов,
оформление, просмотр и отмену брони. Фреймворк выбираете сами, данные храните в PostgreSQL.
Фронтенд предоставляет Хекслет — готовое приложение, которое подключается к вашему API
и работает только тогда, когда API отвечает по описанному контракту.

Учебный проект Хекслета: https://ru.hexlet.io/programs/middle-python

Как это должно работать: https://files.hexlet.app/a/76p1kx

## Стек

- **Язык:** Python 3.12+
- **Фреймворк:** FastAPI + Uvicorn (ASGI)
- **Управление зависимостями:** `uv` (Python), `npm` (Node.js для фронтенда)
- **Инструменты качества:** Ruff (линтер и форматтер), строгие докстроки в стиле Google
- **Сборка и автоматизация:** GNU Make
- **База данных:** PostgreSQL (подключение через `DATABASE_URL`)

## Требования

Для локальной разработки убедитесь, что у вас установлены:
- Python 3.12 или выше
- Менеджер пакетов [`uv`](https://docs.astral.sh/uv/)
- Node.js и npm (для сборки фронтенд-ассетов)
- GNU Make

## Установка и запуск

1. Клонируйте репозиторий и перейдите в директорию проекта:
   ```bash
   git clone https://github.com/unlaudd/middle-python-project-428.git
   cd middle-python-project-428
   ```

2. Установите все зависимости (Python и Node.js):
   ```bash
   make install
   ```

3. Соберите фронтенд (скопирует готовые статические файлы в директорию public/):
   ```bash
   make build
   ```

4. Запустите сервер разработки:
   ```bash
   make start
   ```
   По умолчанию сервер слушает порт 8080. Чтобы изменить порт, используйте переменную окружения: PORT=9000 make start.

## Проверка работы
После запуска сервера вы можете проверить основные эндпоинты:

```bash
# Проверка API (должен вернуть пустой массив на текущем этапе)
curl http://localhost:8080/api/cities
```

```bash
# Проверка SPA-fallback (должен вернуть HTML-страницу, а не 404)
curl -s http://localhost:8080/lookup | head -n 1
```

```bash
# Проверка HEAD-запроса
curl -sI http://localhost:8080/api/cities | head -n 1
```

## Разработка и качество кода
Проект использует Ruff для обеспечения единого стиля кода и проверки докстрок (Google Style).
```bash
# Проверка кода линтером
uv run ruff check .
```

```bash
# Автоматическое исправление простых ошибок и форматирование
uv run ruff check --fix .
uv run ruff format .
```
